**Note**: All referenced screenshots are available in the `/screenshots` directory of the repository.

## Student Journey

### 1. Landing on the Website

**Flow**: Public User → Student Registration → Dashboard Access

#### Step 1: Homepage Visit
- User lands on the main homepage
- Navigation shows "LOG IN" and "SIGN UP" options
- Course catalog is visible for browsing
- University listings are accessible

#### Step 2: Course Exploration
- Browse available courses without registration
- View course details and descriptions
- See university information
- Compare different programs

### 2. Student Registration Process

#### Step 2.1: Registration Page Access
- Click "SIGN UP" button from navigation
- Navigate to registration page
- Choose "Student Registration" tab

**Screenshot Reference**: `screenshots/Phase 2 - Front End Screen/Register - 1stScreen.jpeg`

#### Step 2.2: Fill Registration Form
- Enter personal information:
  - Full Name
  - Email Address
  - Phone Number
  - Country Selection
  - Password
- Accept terms and conditions
- Click "Register" button

#### Step 2.3: Email Verification
- Check email for verification code
- Enter OTP code on verification screen
- Complete email verification process

#### Step 2.4: Phone Verification
- Receive SMS with verification code
- Enter phone OTP
- Complete phone verification

#### Step 2.5: Registration Success
- See registration success message
- Automatic redirect to login page

**Screenshot Reference**: `screenshots/Phase 2 - Front End Screen/Register - 2nd screen - successfully.jpeg`

### 3. Student Login Process

#### Step 3.1: Login Page
- Navigate to login page
- Select "Student" from user type dropdown
- Enter email and password

**Screenshot Reference**: `screenshots/Phase 2 - Front End Screen/Login Screen.jpeg`

#### Step 3.2: Dashboard Access
- Successful login redirects to student dashboard
- Dashboard shows personalized content
- Navigation updates to show logged-in state

### 4. Student Dashboard Features

#### Step 4.1: Dashboard Overview
- View enrolled courses
- Check account status
- Access quick actions
- See notifications and updates

#### Step 4.2: My Courses Section
- View all enrolled courses
- Track course progress
- Access course materials
- View completion status

**Screenshot Reference**: `screenshots/Phase 2 - Front End Screen/My Course - 3rd Screen.jpeg`

#### Step 4.3: Account Details Management
- Edit personal information
- Update contact details
- Change password
- Manage notification preferences

**Screenshot Reference**: `screenshots/Phase 2 - Front End Screen/Account Details - Course - 4th Screen.jpeg`

### 5. Profile Management

#### Step 5.1: Edit Profile Information
- Navigate to account details section
- Click "Edit" on profile information
- Update name, email, phone, or other details

**Screenshot Reference**: `screenshots/Phase 2 - Front End Screen/Name Edit Screen - 2nd.jpeg`

#### Step 5.2: Name Change Process
- Enter new name in edit form
- Confirm changes
- See success notification

**Screenshot Reference**: `screenshots/Phase 2 - Front End Screen/Name Changing - 3rd Screen.jpeg`

#### Step 5.3: Changes Confirmation
- Profile updated successfully
- New information displayed
- Changes reflected across platform

**Screenshot Reference**: `screenshots/Phase 2 - Front End Screen/Name changed - 4th Screen.jpeg`

### 6. Password Recovery

#### Step 6.1: Forgot Password
- Click "Forgot Password" on login page
- Enter registered email address
- Submit password reset request

**Screenshot Reference**: `screenshots/Phase 2 - Front End Screen/Forgot Password screen.jpeg`

#### Step 6.2: Reset Password Process
- Check email for reset instructions
- Click reset link
- Enter new password

**Screenshot Reference**: `screenshots/Phase 2 - Front End Screen/Forgot Password Screen 2nd.jpeg`

### 7. Course Enrollment & Payment

#### Step 7.1: Course Selection
- Browse course catalog
- Click on desired course
- View course details and price

#### Step 7.2: Enrollment Process
- Click "Enroll Now" button
- Review course information
- Proceed to payment

#### Step 7.3: Payment Gateway
- Redirected to Razorpay payment interface
- Choose payment method
- Complete secure payment
- Receive confirmation

#### Step 7.4: Course Access
- Return to dashboard
- Course appears in "My Courses"
- Access course materials
- Begin learning journey
